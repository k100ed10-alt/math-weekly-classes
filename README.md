# حصص الرياضيات الأسبوعية

جدول حصص للصفوف 5–12. الطالب يدخل برمز من المعلم. المعلم يضيف الحصص بعد الرقم السري.

## التشغيل
افتح `index.html` أو فعّل GitHub Pages على فرع `main`.

## تجريب
- معلم: `123456`
- طالب الصف الخامس: `حصة5` وهكذا حتى `حصة12`

## Firebase
ضع المفاتيح في `js/firebase-config.js`
- settings/teacher.secretCode
- weeklyClasses
- studentCodes/{grade}.code
